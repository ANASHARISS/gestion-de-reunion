Questions fréquentes

Comment planifier une réunion ?

Pour planifier une réunion, suivez ces étapes simples :

1 Cliquez sur le bouton "Créer" dans la barre latérale ou sur "Planifier une réunion" depuis l'accueil
2 Remplissez le formulaire avec : titre, date, heure, type (En ligne/Présentiel/Mixte) et description
3 Cliquez sur "Créer" pour finaliser la planification

Note : Votre réunion sera automatiquement visible dans la section "Planification" et apparaîtra dans les statistiques.

Comment modifier une réunion existante ?

Pour modifier une réunion existante :

1 Allez dans la section "Planification" depuis le menu latéral
2 Trouvez la réunion que vous souhaitez modifier dans la liste
3 Cliquez sur "Voir" pour accéder aux détails
4 Cliquez sur "Modifier" pour éditer les informations

Informations modifiables : titre, date, heure, type de réunion, description

Note : Les modifications sont sauvegardées automatiquement et visibles immédiatement.

Comment annuler une réunion ?

Pour annuler une réunion :

1 Accédez à la section "Planification"
2 Localisez la réunion que vous souhaitez annuler
3 Cliquez sur le bouton "Annuler" à côté de la réunion

Ce qui se passe après l'annulation :

  • La réunion disparaît de la liste "Planification"
  • Elle apparaît dans l'"Historique" avec le statut "Annulée"
  • Les statistiques sont mises à jour automatiquement
  • Le taux d'annulation est recalculé

Note : L'annulation est définitive mais la réunion reste visible dans l'historique pour traçabilité.

Comment voir mes réunions passées ?

Pour consulter l'historique de vos réunions :

1 Cliquez sur "Réunions" dans le menu latéral
2 Vous verrez un tableau avec toutes vos réunions
3 Cliquez sur "Voir les détails" pour plus d'informations

Informations disponibles dans l'historique :

  • Titre de la réunion
  • Date et heure programmées
  • Statut : Active (verte) ou Annulée (rouge)
  • Actions pour voir les détails complets

Note : L'historique inclut toutes les réunions créées, qu'elles soient actives ou annulées, triées par date de création.
